# *Programa de teste "and-or-not"*
 Fiz este programa com o objetivo de aprender a utilizar os operadores "and", "or" e "not" na linguagem ![Python](https://img.shields.io/badge/-Python-333333?style=flat&logo=python). A ideia por trás dele é simples, é um programa que ajuda o usuário a saber se o gasto mensal de água por metro cúbico do imóvel no qual ele mora está alto, moderado ou baixo. O usuário digita o tipo de imóvel (tendo que digitar entre 3 opções: "Casa, "Apartamento ou "Comercial") e logo após isso é requisitado o gasto mensal de água do imóvel e então finalmente o programa diz para o usuário se seu consumo mensal de água é alto, moderado ou baixo.
