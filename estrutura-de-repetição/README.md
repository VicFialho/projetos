# PRÁTICA ESTRUTURA DE REPETIÇÃO
## Fiz este programa com o objetivo de entender e treinar o uso das estruturas de repetição na linguagem  ![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white). Ele pede para um certo número de usuários avaliar o atendimento de um estabelecimento fictício entre as notas "Excelente", "Bom", "Ruim". Ele faz isso usando um operador "for" para conseguir executar a repetição da avaliação, sem ele o programa não funcionaria, o programa também garante que o usuário escreva uma das 3 respostas aceitas com o operador "while" presente na linha 10, e os operadores "if" e "elif" nas linhas 15 e 17 realizam a contagem das avaliações, após um certo número de repetições o programa exibe o número de avaliações "Excelente" e "Ruim".
