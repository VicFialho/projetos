# PRÁTICA PARA O USO DE IF, ELSE E ELIF.
Fiz este programa com o intuito de praticar o uso do else, if e elif no ![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white). É um programa bem simples que mostra o desconto de uma compra baseado no valor da própria compra, o programa faz esse cálculo multiplicando o valor da compra pelo valor decimal do desconto que deve ser aplicado, os descontos são respectivamente 0,05 0,10 e 0,15 e eles são aplicados em compras com um valor abaixo de 200, igual ou maior que 200 mas menor que 300 e maior que 300 respectivamente.
