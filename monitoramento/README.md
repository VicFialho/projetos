# MONITORAMENTO DE RESERVATÓRIO DE ÁGUA
Fiz este programa para compreender um pouco a criação e a utilização de listas, funções e bibliotecas em python. Este sistema basicamente informa ao usuário se o nível de um reservatório de água é crítico ou não baseado em um input que o usuário dá ao sistema, ele faz isso usando de base na função ***verificar_nivel***, esta função basicamente utiliza de base a lista mensagem para definir a mensagem que o sistema irá devolver para o usuário após ele informar o nível do reservatório, caso seja nível 1 o sistema irá mostrar a mensagem da posição 0 na lista, caso seja nível 2 ele irá mostrar a mensagem da posição 1 e assim por diante.
