# Projeto de teste - consumo mensal de energia (Python)
 Este projeto foi feito com o objetivo de entender e me aclimatar com o uso do Git e o Github, então fiz algo mais simples. Este programa se utiliza da linguagem Python para calcular o consumo mensal de um eletrodómestico qualquer que você tenha em sua casa. Ele primeiro pega o nome do aparelho, depois sua potência e então seu tempo médio de uso diário, logo após isso faz uma multiplicação entre a potência, o tempo médio de uso pelo núemro de dias em um mês (30) e então divide por 1000. Não é nada muito complexo mas pretendo treinar construindo coisas mais complicadas daqui em diante.
